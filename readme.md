# Smart File Organizer

A Python application that scans folders, detects duplicate files, organizes files by category, and generates reports.

## Features

- Scan folders recursively
- Detect duplicate files using SHA-256
- Organize files by type
- Generate reports
- Easy to use

## Technologies Used

- Python
- hashlib
- os
- shutil

## Run

```bash
python main.py
```
